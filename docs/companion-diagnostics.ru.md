# Диагностика компаньона

В текущем клиенте ручные запросы `fg_SystemEnable` и `fg_debugmodules`
не дали пользователю видимого ответа. Это не доказывает, что Flowgraph
отключён. В сборку добавлено чтение через существующий API настроек игры.

После запуска игры мод автоматически пишет строки `[companion-diag]`
в `data/mod.log`. Замеры выполняются на игровом потоке через 10, 30, 60
и 120 секунд после первого игрового тика. Ввод в консоли не требуется.

- `console=ready` — мод нашёл объект консоли.
- `fg_SystemEnable=<число>` и `fg_debugmodules=<число>` — прочитанные значения.
- `unavailable` — прочитать значение не удалось; это не равно нулю.

Диагностика ничего не меняет, не выполняет консольные команды и не создаёт
NPC. Эти две настройки сами по себе не подтверждают регистрацию или запуск
`SCO_CompanionProbe`, а также работу следования и охраны. Для этого нужны
отдельные игровые проверки.

Режимы компаньона пока не реализованы. Временный XML диагностического
модуля сохраняется для следующего опыта; архив `Data.p4k` не изменялся.
