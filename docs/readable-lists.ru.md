# Читаемые списки и поиск

Снаряжение, корабли, объекты строительства, комплекты SQ42 и кресла экипажа имеют читаемые подписи. В снаряжении у каждого раскрытого списка есть свой поиск; общий поиск снаряжения действует одновременно. Исходный класс доступен при наведении и остаётся идентификатором для игровых действий.

Названия предметов и кораблей читаются один раз за сессию из установленного русификатора `LIVE/data/Localization/korean_(south_korea)/global.ini`. Это текущий русский слот из `languages.ini` и `user.cfg` пользователя. Изменений русификатора нет; его содержимое не копируется в проект и не включается в пакет. Отсутствующие названия заменяются читаемой расшифровкой классов. Некоторые официальные имена в самом русификаторе оставлены на английском.

Поиск учитывает часть названия, регистр русского и английского текста, внутренний класс и русскую расшифровку типа предмета. Несколько слов должны встречаться в объединённой подписи. Например, `P4`, `винт`, `behr` и `баллист` находят соответствующие винтовки по разным признакам. Номера вариантов сохраняются в расшифрованных названиях; полное различие классов всегда видно в подсказке.

Поиск добавлен в кресла экипажа, личный флот, места исследования и цели маршрута. Поиск мест учитывает систему. Имена кораблей личного флота и точек маршрута, заданные пользователем, сохраняются.

При фильтрации выбор хранится исходным индексом или ID, а не номером строки результатов. Скрытие ранее выбранного элемента не заменяет его автоматически. При пустом списке результатов отображается сообщение в раскрытых списках снаряжения и исследования; выбор «Нет» для снаряжения доступен всегда.

Проверка до установки: Release DLL, независимый тест разбора локализации и сохранения вариантов, SDK header gate и 19 тестов gate. На установленном словаре найдено 1224 точных соответствия из 1489 строк каталога предметов и 239 из 1102 строк каталога кораблей; остальные используют резервные подписи. Поиск и отрисовка новой DLL в игре ещё требуют проверки после установки.
