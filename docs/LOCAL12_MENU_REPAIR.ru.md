# Local12: восстановление каталогов и настроек модулей

- Включён существующий пакет picker_catalog: 1109 строк классов кораблей и
  2239 строк типов NPC. Сами списки не заменялись и классы не подменялись.

  он включается только при g_offline && SpawnerReady(). Провайдер по-прежнему
  проверяет офлайн-допуск, владение, класс и положение игрока. Ответ команды
  не считается доказательством появления корабля.

  (float, default 10, диапазон 1–10000). Ранее чтение отсутствующей настройки
  отклоняло включение до обращения к игровому обработчику.

  лимит 63 UTF-8 байта и отклоняли загрузку обоих модулей.

  перемещения: теперь прямо сказано, что именно эта вкладка ещё не подключена
  к game.relocation. Сам перенос дома/этой вкладки пока не реализован.
