# Локальный сервер и «Мой флот»

Это экспериментальный учёт кораблей с постоянной базой. Он работает рядом
с клиентским офлайн-модом и не заменяет сервер симуляции CIG.

## Запуск

1. Откройте папку server возле sc-offline.exe.
2. Один раз запустите Connect-Mod.cmd и выберите папку русского лаунчера.
3. Запустите Start-Server.cmd. Откроется русская страница управления.
4. На пустой базе нажмите «Добавить пример: Gladius», либо добавьте свой корабль
   с точным игровым классом (например AEGS_Gladius).
5. Запустите игру обычным русским лаунчером. Оставьте сетевую блокировку включённой.
6. M → Корабли → Мой флот → «Обновить мой флот». Выберите корабль и нажмите
   «Создать выбранный корабль моего флота» один раз, в открытом месте.

Корабль создаётся на 30 м выше игрока. Движок пытается посадить игрока в кресло
пилота. Сервер записывает «создан в сессии» после фактического появления entity.
Это не подтверждение успешной посадки, загрузки всех компонентов или груза.
Обычный список «Создание корабля» независим и сервером не учитывается.

## После выхода и при ошибке

Записи базы сохраняются сразу. После выхода запустите Recover-Bridge.cmd,
выберите папку лаунчера и подтвердите, что игра закрыта. Учёт созданных кораблей
вернётся в домашнее хранилище. Незавершённый журнал архивируется.
Это пока не сохранение физического корабля: следующий запуск создаёт новый экземпляр.

Если подтверждение потеряно, кнопка создания блокируется. Не удаляйте
bridge-pending.txt вручную и не пытайтесь создавать тот же корабль повторно.
При восстановлении сервер дополнительно проверяет отсутствие StarCitizen.exe.

## Файлы и ограничения

- server/server-state/offline.sqlite3 — постоянная база; сохраняйте папку
  server-state при обновлении. На странице есть резервное копирование SQLite.
- data/bridge.ini — порт и локальный токен; не отправляйте его другим людям.
- data/bridge-pending.txt — журнал незавершённой операции.
- Доступ только 127.0.0.1:18870. Привязка сервера не требует аккаунта.
- Python должен быть установлен; на этом компьютере используется Python311.
  Start-Server.cmd ищет его, затем python в PATH. Это исходный сервер, не EXE.
- Учёт количества предметов и денег на странице пока не связан с игрой.
- Груз, повреждения, реальные контейнеры, экипировка, ASOP и ангары не подключены.
- Не запускайте второй сервер на том же порту; повторный запуск не открывает базу
  до успешного bind. Связь и создание на конкретном клиенте проверяются отдельно.

## Проверка 11 октября 2026 года

Release собран; 18 тестов Python-сервера прошли. Собранный C++ HTTP-мост
проверен через временный сервер: reserve/confirm, конфликт версии и сохранение
неопределённого журнала. Протокол проверен отдельным native тестом.

Python-сервера запись deployed сохранилась, незавершённых резервирований нет.
Полёт, топливо и восстановление физического корабля после выхода не проверены.
