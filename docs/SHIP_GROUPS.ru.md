# Корабли: производитель, тип и сортировка

Установлено 15 октября 2026 без запуска игры.

В M → Корабли и M → Корабли → Мой флот появились фильтры «Производитель»,
«Тип корабля» и сортировка по производителю, типу или точному имени класса.
Можно вернуть порядок каталога / флота. По умолчанию — производитель.
В веб-панели такие же фильтры добавлены в список добавления корабля.

Фильтры комбинируются с поиском. Сортируется только отображение: классы, строки
разных пакетов, принадлежность и данные флота не заменяются. Выбранный веб-класс
сохраняется при смене фильтра с отметкой «вне фильтра»; в игровом «Мой флот» скрытый
выбранный корабль не доступен для вызова до возврата в видимый список.

Типы: боевые, транспортные, исследовательские, промышленные, поддержка, гоночные,
многоцелевые, начальные, наземная техника и «Не определён».
Основа — публичные поля type/manufacturer официальной RSI Ship Matrix, снимок 15.10.2026:
https://robertsspaceindustries.com/en/ship-matrix
https://robertsspaceindustries.com/ship-matrix/index
Код сопоставления/интерфейса написан Codex; не заимствован из форка.

1109 точных классов: 831 сопоставлен с типом, 278 остаются «Не определён».
Технические AI/PU/Unmanned-варианты при надёжном совпадении наследуют роль базовой
модели. Это классификация для поиска, не подтверждение доступности, исправности
или появления варианта в игре. Неоднозначные сопоставления не используются.
Constellation Mk V Centaurus: RSI / Многоцелевые.

Проверено: 96 серверных тестов; 18 workflow-тестов модулей, включая новые фильтры
на реально загружаемом spawn.dll на русском/английском; SDK fleet flow.
Сохранены дубликаты пакетов, пагинация, точный выбор, неизвестные модели; проверены
недопустимые индексы. В браузере RSI + Многоцелевые + Centaurus даёт ровно один
класс RSI_Constellation_Mk5_Centaurus. Смена фильтра не подставляет другой корабль.
База живого сервера до/после совпала по всем таблицам; INI, launcher и ships.txt
побайтно сохранены. Резервная копия и SHA256: INSTALLED.json рядом с отчётом.
