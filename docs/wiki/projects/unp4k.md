## Чем полезен

Чтение отдельных P4K/DCB записей и XML по запросу. Может сократить место для временных выгрузок.

## Что проверено

README, spec.md и MIT LICENSE прочитаны. По README unp4k.fs даёт read-only виртуальный диск и конвертацию по требованию.

## Что у нас

Полезна идея выборочного чтения вместо полного извлечения. Наш каталог должен оставаться привязан к версии и SHA локальных данных.

## Ограничения

Виртуальное монтирование требует Dokan, он не устанавливался. Совместимость с нашей DataCore и полнота root-records требуют проверки; запись в P4K не нужна.

## Следующий шаг

Сначала испытать извлечение одной записи на копии данных и сравнить с текущим парсером, без установки драйверов и полной распаковки.
