## Чем полезен

Общие API сущностей, владения, хранения, интерфейса и контрактов игровых сервисов.

## Что проверено

Точный core pin, опубликованные SDK-заголовки, ABI 1.1; внешние модули собраны против опубликованного SDK.

## Что у нас

Local11 использует этот core и SDK 2.2.0; 17 проверок внешних модулей прошли.

## Ограничения

Наличие заголовка или capability не означает готовый адаптер игры. G2-перемещения и отдельные игровые сервисы недоступны.
