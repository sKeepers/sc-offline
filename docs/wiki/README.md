# Вики полезных проектов

Материалы, найденные и просмотренные **14–15 октября 2026 года** для нашей локальной
сборки Star Citizen. Это база знаний по зафиксированным снимкам, а не заявление
о самых последних версиях всех аналогов. Обновление карточки требует новой проверки.

**Открыть с поиском:** [локальная HTML-вики](index.html). Работает без сервера,
интернета и внешних библиотек. На GitHub пользуйтесь страницами ниже; HTML нужно
скачать и открыть в браузере.

## Наша текущая точка

Установлен **0.7.8.3 / Local12 candidate**, SDK 2.3.0, сервер 0.3.4. Сохранения и
локальный учёт покупок сохранены. Игровая приёмка этой версии ожидается. Возврат
домой и применение старых XML-комплектов недоступны; новые игровые окна переведены
частично. Старые наблюдения Andromeda относятся к Local10.

## Чего пока не найдено

В просмотренных материалах нет подтверждённого готового решения для постоянного
восстановления наших NPC между запусками, физической выдачи покупки в native-инвентарь,
полного цикла личного ангара/лифта/ATC, автозапуска двигателей или общего multiplayer-мира.
Название API, успешная сборка, описание автора и запись журнала не закрывают эти задачи.

## Происхождение

Карточки составлены Codex по сохранённым обзорам `forks-and-alternatives-20261014`,
`additional-sources-20261015`, `useful-projects-20261015`, проверкам оригинала/SDK и фактической установке Local12.
Каждая карточка содержит ссылку на точный SHA, уровень проверки и следующий шаг.
Материалы с неизвестными или ограничивающими условиями отмечены отдельно. Собственная
реализация по идее аналога не означает, что его код был скопирован или установлен.
Личные базы, журналы, токены и игровые ресурсы в вики не включены.
