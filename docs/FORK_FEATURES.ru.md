Локальный сервер 0.3.1 добавляет инструменты к нашей Local10. Версия игрового лаунчера
и DLL на этом этапе не меняется. Новые модули написаны Codex; исправления 0.3.1 подготовлены Claude, проверены и интегрированы Codex;

Публикуемый исходный пакет не содержит игровых JSON, Data.p4k, личной базы, токенов,
журналов и скриншотов. Каталог извлекается и хранится только на компьютере владельца.

## Уже было в нашей сборке

Учитываемый флот, мост резервирования, ограничения списка ASOP и журнал неподтверждённой
доставки развивались на основе nickcarmichaelw12/sc-offline. Преобразование живого игрока
в entity ID уже используется текущим fleet.cpp. Русификация лаунчера, подсказки плагинов,
новые классы кораблей и безопасная проверка старта уже сохранены в Local10.
Alpha-Rome0 и ReverendOzmund в просмотренных ветках не дали отдельной новой реализации.

## Не реализовано как работающая функция оригинальной игры

* Полное чтение карманов, склада локации и груза корабля, физическая выдача приобретения.
  Нужен опубликованный нативный inventory API с подтверждением контейнера, владельца и количества.
* Полный цикл личного ангара, лифта, размещения и ATC. Отправка Deliver не равна появлению корабля.
* Автоматическое engines_on: отдельного getter/вызова в проверенном SDK нет; слепые toggles не добавлены.
* Полный набор чужих миссий и безусловный межсистемный Travel. Ресурсы не импортированы;
  отключение проверок готовности мира не является реализацией безопасного перехода.
* Полный private-server из Weavor74: доказательств работающего мира в рассмотренном прототипе нет.
* Полный перенос NexusApp/системы рецептов, декодера сканов и overlay; на этом этапе готов
  самостоятельный журнал партий и планировщик, а не всё приложение.

Эти пункты остаются открытыми. Полный исходный запрос на все функции этим этапом не закрыт.

## Проверка пользователем

1. Открыть http://127.0.0.1:18870/tools — каталог, фильтр кораблей, поиск Constellation.
2. Для локального предложения выбрать реальный магазин, подтвердить правило LOCAL_CREDIT,
   указать собственный остаток. На главной странице купить одну единицу при достаточном
   локальном балансе. Это меняет сохранённый учёт; не используйте для проб рабочие предложения.
3. Купленный корабль должен появиться в «Мой флот»; его фактический вызов проверить отдельно в игре.
4. Сохранить маршрут с собственными координатами одной зоны; проверить сохранность после
   обновления страницы. Первую точку планировщик оставляет стартом.
5. Создать партию переработки, дождаться истечения таймера и отметить фактическое получение
   только после наблюдения в игре. Истёкший таймер не означает выданный груз.

Веб-интерфейс и операции протестированы на изолированной базе. Игра для этой работы
не запускалась. Перед установкой выполнена SQLite backup; хэши всех прежних таблиц
совпали после обновления. Конкретный путь backup и SHA256 файлов — локальный INSTALLED.json.
