## Установка и обновление

Скачайте Windows ZIP, распакуйте в отдельную папку, запустите sc-offline.exe. При необходимости задайте `game =` в sc-offline.ini. Для веб-панели нужен Python 3.11+ без внешних pip-зависимостей; адрес http://127.0.0.1:18870/ . Для привязки флота используйте server/Connect-Mod.cmd.

Перед обновлением закройте игру/лаунчер и сделайте backup. Сохраните свой sc-offline.ini, пользовательские данные/настройки из data и server/server-state. Сначала перенесите их в новую папку, затем наложите файлы нового релиза; файлы, отсутствующие в поставке, не удаляйте. Подробности и системные изменения описаны в RELEASE.ru.md/docs/launcher.md внутри архива.

## Публикация и доказательства

В релизе: Windows ZIP, complete-source ZIP со sco-core/лицензиями и SHA256SUMS.txt. SHA-256 вложений сверены с GitHub. Персональные профили, сохранения, токены, пароли, БД, журналы и ресурсы/переводы игры исключены. OfflineDB — публичный шаблон upstream.

Release EXE/DLL собраны; native localization tests, SDK gate/tests, ImGui pin, проверки профиля/отчётов, самопроверка лаунчера после распаковки и 24 Python-теста сервиса прошли локально. Это не подтверждение функций в игре или статуса всего GitHub CI.

Меню M, собственные плагины и веб-панель остаются русскими; будущий общий языковой C-сервис sco-core будет отдельным этапом. Полная симуляция dedicated server, реальный общий инвентарь/бой, медицинские/корабельные кровати и надёжное следование компаньонов не реализованы.

Main содержит документацию и прежний код; исходники Local 4 находятся в ветке codex/release-0.7.7-ru-local-4 и теге ru-local-0.7.7-4. Разработка с помощью Codex; часть исследовательских моделей — с помощью Claude. Авторство ChrisWareOffline/scubamount и лицензии сохранены.
