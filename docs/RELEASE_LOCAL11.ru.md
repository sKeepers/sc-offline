## Ограничения кандидата

Игра при сборке не запускалась. Запуск, безопасное появление, кресло, питание и
двигатели требуют новой приёмки именно этой версии. Подтверждения старой Andromeda
относятся к Local10. Команда spawn не считается доказательством появления.
Домашняя точка и старые XML-комплекты сохраняются, но автоматический перенос домой
и применение XML в новой основе недоступны. Первый старт — обычное появление.
Новые оригинальные окна переведены частично. Автовключение двигателей не реализовано.
Multiplayer в пакете отключён; наличие исходного модуля тега не означает общего мира.
Сохранение NPC между сессиями, native aUEC и физическая выдача покупок не заявлены.

## Установка и данные

Распакуйте в отдельную папку. Сначала сохраните старые INI, data/homes, data/sessions,
data/storage, local/host и server/server-state. Не запускайте две версии с одной базой.
Нужен Python 3.11+. server/Start-Server.cmd запускает локальную панель;
связь мода настраивается server/Connect-Mod.cmd. Не подменяйте рабочую базу пустой.
Начните с TESTING-LOCAL11.ru.html. Ссылки открываются в отдельной вкладке.
Не используйте домашний/возобновляемый старт в этом кандидате.

Пакет не содержит игру, извлечённый ценовой каталог, базы, токены, дома, профили,
журналы или другие личные данные. Каталог цен извлекается локально владельцем игры.
Полные соответствующие исходники всех собранных модулей и закреплённого sco-core
в complete-source ZIP. Основная C++-ветка GitHub пока прежняя; этот ZIP соответствует Local11.
