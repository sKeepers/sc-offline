# Старт в выбранном месте

В M → Перемещение выберите систему и место, затем нажмите
«Начинать игру в выбранном месте». Настройка применяется при следующем запуске,
сохраняется отдельно от автосохранения и имеет приоритет перед Daymar/F7/resume.

Чтобы начинать внутри города или на станции, встаньте на свободный пол вне
корабля и нажмите «Начинать игру в моей текущей точке». Сохраняются координаты
в именованных зонах. Точная кровать корабля и медицинская регистрация не сохраняются.
Кнопка «Вернуть старт по настройкам лаунчера» отключает этот выбор.

boot_map = PU_All нужен для Stanton, Pyro и Nyx одновременно. Названия в списке
не гарантируют, что зона действительно загружена. Мод проверяет её текущий ID,
запрашивает выход из связанного кресла/кровати штатным методом и ждёт готовности
персонажа. Если место не стало доступно за 120 секунд, запрос отменяется,
но выбранная настройка сохраняется. Подтверждение прибытия основано на фактической
позиции, а не только на возврате функции.

Кнопки перемещают персонажа. Корабль, его предметы и груз не переносятся вместе
с ним. Для планет без известного радиуса выбирается орбитальная точка. Это не
посадка в город. Для Орисона используйте сохранённую точку внутри города;
телепорт к Crusader сам по себе не означает прибытие в Орисон.

Хранение: data/storage/quantum.db, ключ startup.v1. Предыдущие сохранения
exploration.db и F7 не изменяются выбором стартовой точки.

Состояние на момент создания документа: Release собран; живая проверка новой
функции ещё выполняется. Полное сохранение реальных предметов и груза отдельно
исследуется по материалам inventory-20261011.
