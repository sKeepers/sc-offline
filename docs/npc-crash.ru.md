# Сбой при создании Transport

10 октября 2026 года, 22:12:56: mod.log зафиксировал создание `Transport`, затем Game.log — фатальную ошибку:

```text
CSCActorResultStateGround::Enter: Missing some required components on actor Transport_200006372646
Is GPU crash: No
```

Класс есть в реестре игры и исходном npcs.txt, но его создание в установленном LIVE 4.10.196.36804 приводит к отсутствию обязательных компонентов персонажа. Проверка наличия имени в реестре этого не выявляла.

Исправление исключает Transport из списка NPC и отклоняет его в общей функции создания объектов до обращения к движку. Защита действует также для экипажа и вызовов плагинов, использующих эту функцию. Срабатывание записывается в mod.log. Это блокировка подтверждённого проблемного класса; совместимость всех остальных NPC не проверена. Список в npcs.txt сохранён, чтобы не перезаписывать личные изменения.

Отчёт запуска теперь включает события NPC и строку `- Fatal error message:`. Исторические отчёты остаются без изменений.

Проверка после обновления: заново запустить лаунчер и игру, открыть список NPC — Transport должен отсутствовать. Для первого теста выбрать `PU_Human_Enemy_GroundCombat_NPC_ASD`, количество 1. В предыдущей сессии этот класс успешно создавался в экипаже. Дальнейшую работу NPC и их поведения нужно проверять в игре; автоматические проверки не запускают игровой движок.
