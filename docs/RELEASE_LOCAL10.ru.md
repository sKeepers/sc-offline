# sc-offline 0.7.7 RU / Local10 candidate + сервер 0.3.3

Предварительная сборка для проверки. Полная игровая приёмка ещё не завершена.

## Что вошло после Local6

Русские подсказки плагинов, семь добавленных классов кораблей (включая Constellation
Mk V Centaurus), улучшения старта и терминала, сохранение домашней точки и постоянный
ID профиля. Сервер 0.3.3: локальный учёт покупок/флота, проверяемый каталог базовых цен,
монитор журналов, маршруты и таймеры. Инструкция доступна в /testing и из обеих панелей.

83 серверных теста прошли. EXE/DLL/Exploration побайтно совпадают с установленным
Local10, ранее собранным с настоящим SDK2.0. Отдельные наблюдения пользователя:
Andromeda появилась, посадка и питание работают; двигатели включились вручную через I.
Дом и вызов всех новых моделей пока не подтверждены. Нового игрового запуска при
упаковке не было; бинарники Local10 не пересобирались ради номера серверной версии.

## Запуск и обновление

1. Распакуйте Windows-архив в отдельную папку. Не затирайте старую сборку.
2. Для сервера нужен Python 3.11 или новее (зависимостей вне стандартной библиотеки нет).
   Запустите server/Start-Server.cmd, затем откройте http://127.0.0.1:18870/testing.
3. Если старый сервер уже работает на18870, штатно остановите его перед запуском нового.
4. Связать сервер с папкой мода можно через server/Connect-Mod.cmd. Личные данные,
   старые server-state, профиль, дома и sc-offline.ini сохраняйте отдельно; не подменяйте
   рабочую базу пустой базой из тестов. В этом архиве базы и токена нет: они создаются локально.
5. При пустом «Мой флот» сначала добавьте принадлежащий вам корабль в панели.
   Корабли творческого каталога и записи владения — разные списки.

Каталог цен из игры в архив НЕ включён. Его извлекают на компьютере владельца;
без проверенного локального каталога соответствующие функции недоступны.

## Ограничения

LOCAL_CREDIT — отдельный учёт, не native aUEC. Покупка не выдаёт предметы в карманы.
Таймер не подтверждает получение груза. Автоматическое включение двигателей не готово.
Штатный цикл ангара/лифта/ATC, межсистемные переходы, следование/охрана NPC и общий
многопользовательский мир не заявлены работающими. Схема сервера2; кандидат схемы3
не включён. Известная мелочь панели: фоновое восстановление фокуса может прокрутить страницу.

Архив не содержит игры, игровых JSON/архивов, личной базы, профиля/домов, токенов,
логов, скриншотов и папки обмена. Не используйте эту сборку для подключения к CIG.
Соблюдайте инструкции лаунчера по возврату в обычный режим.
