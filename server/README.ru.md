# Локальный сервер: русский интерфейс

Инструкция находится в ../docs/local-fleet-server.ru.md.
Start-Server.cmd запускает сервер и страницу управления.
Connect-Mod.cmd связывает сервер с папкой русского лаунчера.
Recover-Bridge.cmd восстанавливает учёт только после закрытия игры.

Данные: server-state/offline.sqlite3. Сохраняйте всю папку server-state при обновлении.
Учёт предметов, денег и ангаров на странице не меняет соответствующие игровые объекты.
Привязанный мост создаёт только корабли через «Мой флот» в меню мода.

Тесты: python -m unittest -v test_server. C++-мост проверяется отдельно
через test_native_bridge.py и собранный local-fleet-bridge-test.exe.
Имитированное entity-подтверждение в этом тесте не является игровым тестом.

Авторство и лицензия — ATTRIBUTION.md и LICENSE.

## Локальные приобретения, сервер 0.2.4

Веб-панель показывает предложения, заданные владельцем для LOCAL_CREDIT, и отдельный
реестр приобретённых предметов. Операции /shops/source, /shops/offer, /shops/quote,
/shops/purchase требуют существующей авторизации. /api/v1/shops читает предложения,
квитанции и holdings. Списание, остаток и квитанция меняются одной SQLite-транзакцией;
повтор Idempotency-Key возвращает прежний результат. profile.credits — единственный баланс.
Существующий склад inventory сохранён отдельно: его ручные записи не выдаются за покупки.
Настоящие цены/остатки магазина, native aUEC и физическая выдача предметов не подключены.
Состояние отправленной, но неподтверждённой выдачи не допускает повтора.

## Каталог и инструменты, сервер 0.3.0

Страница /tools содержит каталог базовых цен собственной установки, поиск предметов/кораблей,
маршруты в одной системе координат, журнал добытых партий и таймеры переработки.
GET /api/v1/game-catalog и /api/v1/tools защищены тем же локальным токеном.
Каталог находится в server-state/game-catalog: хэши исходных файлов и отдельных записей
проверяются перед использованием. Дробные цены сохраняются как есть. Для локальной покупки
владелец явно выбирает перенос в LOCAL_CREDIT и правило округления, задаёт свой остаток.
Исходный игровой каталог и его неизвестный живой остаток сохраняются отдельно.
Покупка известного корабля добавляет запись в «Мой флот» в той же транзакции; повтор ключа
не создаёт второй корабль. Максимум флота — 256; переполнение отменяет всю покупку.

Планы рейсов и переработки сохраняются в SQLite tool_entries. Маршрут использует ближайшую
следующую остановку, не проверяет препятствия и не управляет игрой. Таймер не доказывает
завершение переработки. Подтверждение пользователя записывается отдельно.

Монитор читает Game.log и mod.log локально, новые события появляются на /tools.
Первый запуск начинается с текущего конца, старые сбои не выдаются за новые. Курсор и события
сохраняются в log-observer.json. Ротация и неполные строки учитываются. Пути можно указать
через --game-log и --mod-log; внешних отправок и Discord нет. Совпадение строки не является
подтверждением запуска двигателя или физической доставки. Для другой установки укажите
её путь к Game.log явно.

Новые модули и панель написаны Codex независимо. Идеи формата и сценариев сопоставлены со
sc_datapack, StarBreaker, star-citizen-live, NexusApp и sc-nav; их код и бинарники не включены.
P4K AES-CBC формат сопоставлен с опубликованным unp4k/StarBreaker; распакованные игровые
данные остаются локальными и не входят в публичный исходный пакет.
