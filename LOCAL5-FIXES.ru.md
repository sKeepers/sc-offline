# 0.7.7 / Local 5 — исправления регистрации и локализации

Исправлены превышавшие лимит SDK заголовки loadout.equip/loadout.wear и
идентификатор вкладки персонажей: loadout.npcs принадлежит loadout.
Ссылки на владельца вкладок игрока/персонажей и экипажа очищаются при выгрузке
и неудачной загрузке. Создание персонажей регистрируется после успешной подписки.

Одинаковые переводы больше не объединяют идентификаторы кнопок. У строк действий
лаунчера сохранены явные ключи; скопированные подписи основной кнопки используют
постоянный идентификатор. После Seal каталог неизменяем; каждый Load до Seal
заново использует английский fallback. Для смены языка нужен перезапуск.

При отсутствии пути игры текущая папка не читается как игра. Не-ASCII папки
локализации безопасно пропускаются, ANSI-комментарии user.cfg не мешают читать
ASCII g_language. Прежнее правило первого повторного g_language сохранено:
поведение игры при дубликатах не доказано. UTF-8 локализаций остаётся строгим.
Python validator проверяет те же границы байтов, ASCII trim и конечный backslash.

Проверки: MSVC Release EXE/DLL, собственный native regression10/0,
native UTF-8/UTF-16/каталоги/форматы PASS, en/ru306keys и fonts PASS,
SDK gate47files/300includes,19gate-tests и4NPC-release-tests PASS.
Исходный Local4:3metadata failures и7localization failures воспроизведены.
Проверка metadata статическая; настоящая регистрация вкладок в игре ещё не проверена.

В заголовке лаунчера Local 5. Для проверки после установки запустите
sc-offline.exe, затем игру и проверьте вкладки Игрок, Персонажи, Эскадрилья42.
Следование/охрана NPC остаются отключены; этот hotfix не устраняет их сбой.

Происхождение: исправления выполнены Codex на текущем исходном коде с учётом
статически проверенных предложений Claude от13.10.2026. Входящие программы
и тесты Claude не выполнялись. SCO API/ABI и provider lifetime не изменялись.

Дополнительная проверка:13/0 на настоящем sco-core host с настоящим loadout builtin; game/draw/borrow callbacks заглушены. Не игровой тест.
