# sc-offline RU / Local

[Вики полезных проектов](docs/wiki/README.md) — 20 источников, тематические разделы и план применения. [Скачать HTML-вики с поиском](https://github.com/sKeepers/sc-offline/raw/refs/heads/main/docs/wiki/index.html).


**Актуальный предварительный пакет: 0.7.8.1 / Local11 candidate + сервер 0.3.3.**

[Скачать сборку и исходники](https://github.com/sKeepers/sc-offline/releases/tag/ru-local-0.7.8.1-11-server-0.3.3) · [Что изменилось и ограничения](docs/RELEASE_LOCAL11.ru.md) · [Инструкция проверки HTML](docs/TESTING_LOCAL11.ru.html)

Оригинал обновлён до 0.7.8.1, SDK 2.2.0 / ABI 1.1. Сохранены русский лаунчер и
описания плагинов, дополнительные классы кораблей, локальный учёт флота, чтение
исследований и комплектов. Для вызова кораблей используется новый публичный SDK;
команда не считается доказательством появления.

**Перенос домой и применение старых XML-комплектов пока недоступны.** Данные
сохраняются; первый запуск — обычное появление. Новые оригинальные окна переведены
частично. Игровая приёмка этой версии ещё не выполнена; старые наблюдения Andromeda
относятся к Local10. Автовключение двигателей не реализовано.

83 серверных теста, 17 внешних workflow-тестов, 59 admission-сценариев (274 проверки),
379 ключей локализации, профиль и локальные модули прошли автоматические проверки.
Они не заменяют проверку настоящей игры. G1 проверки допуска не отключались.

Windows x64, Python 3.11+ для сервера. Распакуйте в отдельную папку, сначала сохраните
личные данные. Игра, ценовой каталог, токены, базы, дома и профили в пакет не входят.
Откройте TESTING-LOCAL11.ru.html внутри Windows-пакета. Его ссылки открываются в
отдельной вкладке. Не перезаписывайте живую базу пустой при переносе.

**Полные соответствующие исходники Local11 находятся в complete-source ZIP релиза**,
включая закреплённый sco-core и лицензии. Основная C++-ветка main пока более ранняя;
она содержит документы и сервер. Точные SHA и инструкции сборки приведены в ZIP.

Сервер 0.3.3 ведёт локальные покупки, флот, журнал наблюдений, планы маршрутов и
таймеры. Native aUEC, физическая выдача покупок, постоянное восстановление NPC,
безопасный дом, полный цикл ангара/ATC и общий multiplayer-мир не подтверждены.

[Предыдущий Local10 + сервер 0.3.3](https://github.com/sKeepers/sc-offline/releases/tag/ru-local-0.7.7-10-server-0.3.3) остаётся доступен отдельно.
