# 0.7.7 RU / Local 4 — предварительная сборка

Windows x64. Требуется собственная установленная игра. Для веб-панели дополнительно нужен Python 3.11+ (стандартная библиотека, без pip-зависимостей).

## Установка
1. Распакуйте архив в отдельную папку, например `D:\Games\sc-offline-local4`.
2. Запустите `sc-offline.exe`. Лаунчер ищет игру; при необходимости укажите `game =` в sc-offline.ini.
3. В профиле полёта выберите старт, корабль и язык. Смена языка требует перезапуска лаунчера.
4. Меню мода открывается клавишей M. Двигатели в игре включаются I.
5. Веб-сервер запускается при запуске игры или отдельной кнопкой лаунчера; страница http://127.0.0.1:18870/ .
6. Для привязки учёта флота используйте server/Connect-Mod.cmd. Веб-учёт предметов не создаёт физический инвентарь.

Перед заменой старой сборки закройте игру и лаунчер, сделайте резервную копию. Перенесите свои sc-offline.ini, папку data с сохранениями/профилем/настройками и server/server-state; затем наложите файлы нового архива. Не удаляйте пользовательские файлы, которых нет в новом архиве. Игра и её USER/data не входят в архив.

## Возможности и ограничения
306 текстов лаунчера вынесены в UTF-8 en.ini/ru.ini; новые языки добавляются своим словарём. Игровые global.ini читаются локально для названий. Меню M, собственные плагины и веб-панель пока русские; многоязычный ABI плагинов ещё не реализован.

Экспериментальные старты у станций находятся снаружи на корабле, не в ангаре/медицинской кровати. Перенос из исходного spawn в выбранную точку не подтверждён для всех мест. DEFAULT_1 в mobiGlas пока не исправлен; своё имя относится к интерфейсу мода.

NPC follow/guard/leader отключены после сбоя. Диагностические пробы не доказывают безопасность или работающее следование. Сеть передаёт позиции и ограниченные визуальные копии; общей физики, урона, миссий и инвентаря нет. Для VPN настройте multiplayer_allow на обоих ПК. Если UDP64091 зарезервирован Windows, выберите свободный порт, например45091, и проверьте его на обоих ПК.

Сборка/автономные тесты прошли. Визуальная проверка новой локализации и полный игровой прогон этой комплектации пока не выполнены. Оригинальные обновления автоматически не заменяют локальные функции. Лаунчер временно изменяет системные настройки по своей конфигурации: изучите docs/launcher.md. Пользуйтесь автономным режимом, выполняйте штатное удаление мода перед онлайн-игрой.

Архив содержит шаблон OfflineDB из проекта upstream, не персональный файл игрока. Пароли, API-токены, журналы, базы учёта, переводы и ресурсы игры исключены.
